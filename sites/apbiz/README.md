# Apbiz website

The public site for Apbiz Consulting India LLP: one static page (HTML and CSS, no scripts) on warm calm styling, covering GST, income tax and TDS, company law (ROC/MCA) and labour compliance. It is not part of the IBMP application.

- Before it goes live, replace every `91XXXXXXXXXX` in `index.html` with the WhatsApp number (country code 91, digits only).
- Preview: `npx serve sites/apbiz` or any static server.
- The due-dates table is general guidance; review it when the government changes dates.
